# Decisión de remediación de URLs — 26/10/2026

## Alcance y resultado

Se revisaron los candidatos encontrados para las URLs rotas o sin precio positivo del run del 26/10. Tienda Inglesa se excluyó por estar desactivada. Se actualizaron en producción **28 URLs** (7 Ta-Ta y 21 El Dorado), solo en el campo `store_products.url`. No se tocaron precios, nombres, estado activo ni otros datos, y no se lanzó otra run de scraping.

Las rutas nuevas se abrieron en la web de cada cadena. Para los productos de El Dorado, además se verificaron las fichas de catálogo actuales, sus nombres internos, EAN del SKU actual, tamaño y precio disponible. Para Ta-Ta se verificaron las páginas candidatas y se compararon envases cuando había una posible diferencia visual.

## Regla aplicada

- Reemplazar solo si la página candidata existe y la identidad converge: marca, variante/sabor, contenido y nombre interno del SKU; comparar fotos cuando el packaging o el nombre haya cambiado.
- Usar el último precio guardado como control de plausibilidad solo si existe. **Ninguno de los 28 productos seleccionados tenía precio positivo histórico guardado**, por lo que no se pudo hacer una comparación histórica de precio. Los precios abajo son los observados en el candidato actual, no una comparación con el producto anterior.
- El EAN de la tabla identifica el SKU candidato actual; el registro antiguo no guardaba EAN, así que no lo presento como una comparación EAN-a-EAN.
- Si la página candidata falla, la variante no coincide o la evidencia visual contradice el nombre, no reemplazar. Si no hay candidato fiable, dejar el producto activo y su URL tal cual.
